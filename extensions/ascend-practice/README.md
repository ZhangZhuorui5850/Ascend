# Ascend Practice

Ascend 的本地算法刷题端。扩展从 Ascend 读取今日训练、到期复测和题单，将选中的题目展开为普通本地文件，并同步 C++ 草稿与训练结果。

## 使用

1. 在 VS Code 中运行 `Extensions: Install from VSIX...`，选择发布目录中的 `ascend-practice-0.9.4.vsix`。
2. 运行 `浏览器配对新服务器`，填写服务地址。
3. 浏览器打开确认页后点击“允许此设备”，VS Code 会自动完成连接。
4. 从活动栏的 Ascend 视图选择题目。

状态栏中的 Ascend 项可切换服务器、添加连接和管理档案。扩展会在启动时恢复上次连接，并分别显示已连接、服务器离线、授权失效和等待配对状态。手动设备令牌入口保留在命令 `使用设备令牌连接`。

侧栏固定展示“今日训练、到期复习、题库、我的文件夹”四个根节点。题库中的“中关村学院机试学习路线”按九章展开，历年题同时进入专题章和综合章。工具栏提供刷新、搜索和连接设置；网页端设置的计划日期、学习状态、课程章节、来源题单和文件夹位置会同步到对应节点。

“我的文件夹”是个人整理树。目录内支持单选、多选和直接拖拽排序。题目拖到题目行时排在目标题目前面，文件夹拖到文件夹行时排在目标文件夹前面；拖到列表空白处时移动到末尾。题目拖到文件夹行时进入该文件夹。文件夹右键菜单提供新建子文件夹、重命名、移动层级和删除。

资源管理器的 CPP 文件右键菜单提供“添加当前 CPP 到 Ascend”，文件夹右键菜单提供“批量添加 CPP”。扩展上传真实文件名、相对路径和代码内容；Ascend 读取文件头注释与文件名，匹配平台题号，并将原始 CPP 保存为参考代码。

题目采用双编号：标题前的 `01、02、03` 表示当前列表位置，描述中的 `P007` 是服务器永久题号。拖拽会自动更新位置序号，永久题号用于同步、搜索和历史关联。

工具栏搜索会在固定导航内展示匹配结果，清除后恢复四个根节点。题目描述会显示学习状态、课程阶段、本地代码、云端草稿和同步状态；文件夹显示题目总数与复习进度。

拖拽支持多选批量移动，移动完成后可立即撤销。文件夹右键菜单提供置顶、上移、下移；删除时可把题目和子文件夹提升到上一级。扩展会记住展开文件夹和当前选择，个人目录始终按照手动顺序展示。

题目右键菜单可快速修改名称、课程章节、技能标签、难度、阶段、优先级、训练状态、下次复测日期和个人备注。课程章节修改写回 Ascend，与网盘和网页题库同步。本地联动命令可以打开并定位 `main.cpp`、在新窗口打开题目目录，以及把个人文件夹中已打开过的题目生成 `.code-workspace`。

打开题目后，左侧显示只读题面与训练工具栏，右侧打开普通 `main.cpp`。题面使用 KaTeX 渲染 `$...$` 行内公式与 `$$...$$` 块公式，公式资源随扩展提供并支持离线显示。工作区同时包含离线 `problem.md`、公开样例、`custom.in` 和 `.ascend.json`。保存 `main.cpp` 后约 1.2 秒同步云端草稿。草稿带修订号；网页或另一台设备抢先保存时，扩展会暂停自动同步并提供载入云端、保留本地两种显式处理。

首次作答使用题库根目录的 `template.cpp`；本地已有 `main.cpp` 与云端草稿会继续保留。导入的原始 CPP 通过“查看参考 · L4”单独打开，查看行为会进入本次训练的提示级别。

题面工具栏提供公开样例、自定义输入、同步、结果记录、正式评测、参考代码和模板新作答。训练会话持续记录聚焦且活跃的作答时间；模板新作答会先把现有代码备份到 `.ascend-history`，再结束旧会话。

连接档案保存在 VS Code 全局状态，扩展令牌保存在 SecretStorage。每个“服务器实例 + 工作区 + VS Code 运行环境”拥有独立题目路径和会话状态。C++ 编译通过子进程参数数组调用配置的编译器，公开样例在本机执行；编译、运行均限制时长与输出体积，并终止完整进程树。

## 本地开发与打包

```bash
cd extensions/ascend-practice
npm install
npm run typecheck
npm test
npm run test:host
npm run package
```

扩展生成的刷题目录是普通文件夹，可继续使用 Git、clangd、调试器和现有 VS Code 配置。
