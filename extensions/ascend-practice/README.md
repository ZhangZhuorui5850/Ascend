# Ascend Practice

Ascend 的本地算法刷题端。扩展从 Ascend 读取今日训练、到期复测和题单，将选中的题目展开为普通本地文件，并同步 C++ 草稿与训练结果。

## 使用

1. 在 VS Code 中运行 `Extensions: Install from VSIX...`，选择发布目录中的 `ascend-practice-0.8.1.vsix`。
2. 运行 `Ascend: 浏览器配对新服务器`，填写服务地址。
3. 浏览器打开确认页后点击“允许此设备”，VS Code 会自动完成连接。
4. 从活动栏的 Ascend 视图选择题目。

状态栏中的 Ascend 项可切换服务器、添加连接和管理档案。扩展会在启动时恢复上次连接，并分别显示已连接、服务器离线、授权失效和等待配对状态。手动设备令牌入口保留在命令 `Ascend: 使用设备令牌连接`。

侧栏提供“学习模式 / 题库模式 / 目录模式”。点击视图右上角的模式按钮切换；工作区会记住当前模式。学习模式汇总当前课程、今日任务、到期复习和继续上次；题库模式按课程与题单、知识点、来源、难度和学习状态检索；目录模式显示个人文件夹与未整理题目。固定模式根节点的右键菜单也提供模式切换入口。

目录模式是个人整理树。工具栏可新建根文件夹，文件夹右键菜单可新建子文件夹、重命名、移到未整理、选择目标文件夹和删除。目录内支持单选、多选和父子文件夹拖拽；拖到题目上会排在该题之后，拖到文件夹上会进入该文件夹。学习模式与题库模式中的题目可通过右键“移动到文件夹”归档。新版服务器使用单次事务完成批量移动，旧版服务器会由扩展自动改用兼容写法。

题目采用双编号：标题前的 `01、02、03` 表示当前列表位置，描述中的 `P007` 是服务器永久题号。拖拽会自动更新位置序号，永久题号用于同步、搜索和历史关联。

工具栏提供题目搜索与手动顺序、学习状态、名称、永久题号四种排序。搜索期间侧栏只展示一组搜索结果，清除搜索后恢复当前模式。题目描述会显示学习状态、阶段、优先级、本地代码、云端草稿和同步状态；文件夹显示题目总数、到期复测数量与稳定掌握比例。

拖拽支持多选批量移动，移动完成后可立即撤销。文件夹右键菜单提供置顶、上移、下移；删除时可把题目和子文件夹提升到上一级。扩展会记住展开文件夹、当前选择和排序方式。

题目右键菜单可快速修改名称、技能标签、难度、阶段、优先级、训练状态、下次复测日期和个人备注。本地联动命令可以打开并定位 `main.cpp`、在新窗口打开题目目录，以及把个人文件夹中已打开过的题目生成 `.code-workspace`。

打开题目后，左侧显示只读题面与训练工具栏，右侧打开普通 `main.cpp`。题面使用 KaTeX 渲染 `$...$` 行内公式与 `$$...$$` 块公式，公式资源随扩展提供并支持离线显示。工作区同时包含离线 `problem.md`、公开样例、`custom.in` 和 `.ascend.json`。保存 `main.cpp` 后约 1.2 秒同步云端草稿。草稿带修订号；网页或另一台设备抢先保存时，扩展会暂停自动同步并提供载入云端、保留本地两种显式处理。

首次作答使用题库根目录的 `template.cpp`；本地已有 `main.cpp` 与云端草稿会继续保留。导入的原始 CPP 通过“查看参考 · L4”单独打开，查看行为会进入本次训练的提示级别。

题面工具栏提供公开样例、自定义输入、同步、结果记录、正式评测、参考代码和模板新作答。训练会话持续记录聚焦且活跃的作答时间；模板新作答会先把现有代码备份到 `.ascend-history`，再结束旧会话。

连接档案保存在 VS Code 全局状态，扩展令牌保存在 SecretStorage。每个“服务器实例 + 工作区 + VS Code 运行环境”拥有独立题目路径和会话状态。C++ 编译通过子进程参数数组调用配置的编译器，公开样例在本机执行；编译、运行均限制时长与输出体积，并终止完整进程树。

## 本地开发与打包

```bash
cd extensions/ascend-practice
npm install
npm run typecheck
npm test
npm run test:host
npm run package
```

扩展生成的刷题目录是普通文件夹，可继续使用 Git、clangd、调试器和现有 VS Code 配置。
