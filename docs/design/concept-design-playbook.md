# Ascend 大胆动态界面设计手册

这份手册总结 `/concept` 十九套实验主题的生成方法。它的目标不是复刻某一张页面，而是让下一次设计仍然能得到风格鲜明、逻辑自洽、可交互、可落地的新世界。

## 1. 核心判断：主题不是皮肤，而是一套认知模型

普通换肤只改变颜色、圆角和字体；真正的主题会改变用户如何理解任务。

统一生成公式：

> 产品动作 → 认知隐喻 → 视觉语法 → 交互物理 → 状态反馈

以 Ember Forge 为例：

- 产品动作：理解、练习、复述。
- 认知隐喻：加热、锤炼、淬火。
- 视觉语法：暗色炉膛、热橙核心、金属块、火花。
- 交互物理：点击锤击，温度上升，材料发生变化。
- 状态反馈：完成不是一个绿色勾，而是“成品被锻造出来”。

如果只能说“这是暗色橙色主题”，说明主题还没有成立；如果不用看颜色也能预测按钮会怎样响应，主题才真正成立。

## 2. 大胆，但不要失控

大胆不是把所有效果同时开到最大，而是选择一个不可忽略的主张，并让其他元素为它让路。

### 2.1 一个世界只设一条主物理规律

- Kinetic 的规律是“动量会沿轨道传递”。
- Prism 的规律是“复杂内容可以被折射和重新聚焦”。
- Forge 的规律是“理解经过热量与锤炼形成”。
- Gradient 的规律是“训练过程是在损失地形中移动”。
- Kernel 的规律是“抽象必须逐层下潜到机器执行”。

不要在一个页面里同时出现宇宙轨道、玻璃折射、纸张撕裂和液态生长。风格数量多不等于单页隐喻也要多。

### 2.2 用“五个大胆旋钮”，一次最多拧高两个

1. **尺度**：超大标题、核心数字或巨型视觉物。
2. **对比**：黑白、高饱和互补色、极亮焦点。
3. **不对称**：偏心构图、跨网格元素、刻意失衡。
4. **深度**：景深、视差、透视、层叠材质。
5. **节奏**：快速硬切或缓慢呼吸式运动。

一次选择一到两个主旋钮。例如 Monolith 使用尺度与对比，Nocturne 使用深度与慢节奏，Papercut 使用不对称与饱和对比。五项同时拉满会让页面失去信息中心。

### 2.3 70 / 20 / 10 注意力预算

- 70% 是安静、稳定、可阅读的工作表面。
- 20% 是承载主题的结构与材质。
- 10% 是真正惊艳的视觉或动效时刻。

用户先看见 10%，但能否长期使用取决于 70%。大胆设计最常见的失败，是把 10% 扩张成整个页面。

## 3. 十条可复用设计原则

### 原则一：从动词开始，不从形容词开始

“未来感、科技感、高级感”无法指导交互；“折射、追踪、锻造、展开、下潜”可以。

每个新主题先写三个动词，再画页面。例如 AI 研究主题可以是“观测、探测、证伪”，于是自然得到观测站、探针、假设面板和证据状态，而不是泛滥的蓝紫渐变。

### 原则二：先写一句世界宣言

一句话必须同时包含态度和动作：

- “把直觉写成可以被检验的证明。”
- “让每一步搜索，都留下可解释的轨迹。”
- “不要只看最终精度，去观察模型如何抵达它。”

所有主要组件都要能回答：它是否在证明这句话？无法回答的装饰应删除。

### 原则三：让内容名词也进入世界

不要只给通用卡片套外观。任务、进度、错误、完成状态都应被重新命名和组织：

- 任务 → 光束、轨道、证据、音轨、引理、实验运行。
- 进度 → 折射率、温度、潮位、轨道稳定度、损失下降。
- 错误 → 案卷证据、失败样本簇、断裂的证明依赖。
- 完成 → 光束聚焦、材料成形、节点被访问、假设被验证。

这会让主题进入信息架构，而不只停留在背景图。

### 原则四：动效必须承担职责

每个动效至少属于以下一种：

1. **定向**：告诉用户从哪里来、下一步去哪里。
2. **因果**：让输入与结果形成可见联系。
3. **连续**：在视图切换、排序、展开时保持对象身份。
4. **奖励**：只在完成、突破、清零等低频时刻强化反馈。

纯装饰的常驻运动最多保留一到两个，并且必须慢、弱、远离正文。动效数量不是质量，因果清晰度才是。

### 原则五：交互要形成闭环

一个完整微交互包含四步：

> 可发现的入口 → 操作中的物理反馈 → 明确结果 → 下一步出口

例如拖动学习率，不只是滑块移动；损失点应改变路径，指标应更新，界面随后提示“保存为实验”或“对比运行”。如果只有漂亮动画却没有新状态，用户很快会把它当成广告。

### 原则六：用对比建立层级，不靠卡片数量

每页只允许一个一级焦点、二到三个二级区块。通过字号、留白、明暗和运动优先级建立层级。不要把所有内容都装进同样大小、同样阴影的卡片；那会让一切看似整齐，却没有任何决定顺序。

### 原则七：学科隐喻必须在概念上真实

面向专业用户时，错误的学科装饰比没有装饰更糟。

- 数学：呈现命题、引理、反例、依赖与证明缺口，而非随机公式雨。
- 算法：呈现访问序列、不变量、前驱关系、复杂度与运行轨迹。
- 机器学习：呈现基线、超参数、损失地形、消融和失败样本。
- AI 研究：呈现假设、探针、层、表示簇、评测控制和可证伪证据。
- 计算机系统：呈现调用栈、流水线、缓存层次、线程和时钟周期。

主题应帮助理解学科，而不是拿学科符号做赛博朋克壁纸。

### 原则八：响应式保留故事，不强保几何

桌面上的轨道、证明图或实验地形可以是空间构图；手机上不必缩成难以点击的模型。移动端应保留同一个叙事顺序和状态关系，把空间图改写成纵向时间线、步骤流或可横向分页的局部视图。

要保留的是“用户先看什么、再做什么、反馈如何发生”，不是像素位置。

### 原则九：减少动效模式是另一套编排

`prefers-reduced-motion` 不是把时长缩短一点，而是移除视差、旋转、缩放、模糊和长距离位移，保留必要的淡入、状态颜色与即时替换。信息不能依赖动画才能出现，计时器和核心操作必须始终可读、可停、可退出。

### 原则十：通过“第十天测试”

问三个问题：

1. 连续使用十天，它仍然传递状态，还是已经变成墙纸？
2. 用户能否在三秒内找到今天最重要的动作？
3. 去掉动画后，层级、内容和操作是否仍然成立？

任一答案为否，就需要减少效果或重写结构。

## 5. 一套新主题的标准生成流程

### Step 1：先确定产品瞬间

不要从“我要做一套新首页”开始，而要选一个具体瞬间：开始深度学习、理解一个难点、复现一篇论文、定位一次失败、完成无提示回忆。

### Step 2：写出反转句

使用模板：

> `[学习对象]` 不是 `[旧理解]`，而是 `[新的可交互模型]`。

例如：“读论文不是收藏 PDF，而是维护一张假设、证据与反例不断变化的图。”

### Step 3：提取三个动词和一个材料

动词决定交互，材料决定视觉。示例：探测、对齐、证伪 + 光学仪器。不要先挑颜色。

### Step 4：建立映射表

至少映射五项：任务是什么、进度是什么、错误是什么、完成是什么、下一步是什么。如果只有背景和按钮发生主题化，回到这一步重做。

### Step 5：设计一个英雄动作和两个辅助动作

- 英雄动作：首次进入就能理解主题的主交互。
- 辅助动作 A：改变视图或参数。
- 辅助动作 B：完成或验证一个状态。

三个动作足以证明一个概念。概念阶段不要用十几个半成品交互稀释主张。

### Step 6：写动效分镜

按顺序定义：

1. **入场**：先出现方向和主标题，再出现核心对象，最后出现可操作入口。
2. **悬停/指针**：只揭示深度或可操作性，不改变布局。
3. **操作**：输入与对象运动同步，避免延迟到用户误以为没触发。
4. **结果**：状态稳定落位，再提供下一步。
5. **退出**：比进入更快，避免阻塞工作。

实现时用统一 motion token；生产代码避免散落裸时长。优先 `transform` 与 `opacity`，布局重排交给 Motion layout，共享对象用 shared layout 或 View Transition，连续背景运动使用 CSS。

### Step 7：做减法验收

依次关闭粒子、光晕、背景动画、透视和声音。每关闭一层，都问页面是否更清楚。只有能显著强化主题或因果关系的效果才恢复。

## 7. 示例：用同一方法生成一套新主题

假设要为博士研究设计 **Bayesian Foundry / 贝叶斯推断室**：

- 具体时刻：阅读实验结果后更新对一个研究假设的信念。
- 反转句：研究判断不是一次性结论，而是证据到来后持续更新的分布。
- 动词：设定先验、吸收证据、更新后验。
- 材料：半透明概率层、密度曲线、证据砝码。
- 业务映射：任务是待验证假设，进度是证据质量，错误是混杂因素，完成是后验稳定而非“100%”。
- 英雄动作：拖入一条新证据，主分布连续变形，并显示敏感性变化。
- 辅助动作：切换先验；隔离一条证据做 leave-one-out 对比。
- 大胆旋钮：深度 + 不对称。颜色保持克制，避免五项全开。
- 减少动效：分布直接切换，并以数值、区间和文字说明变化。

这个例子可以自然生成布局、文案、数据和动效；它不依赖“再找一套好看的配色”。

## 8. 实现边界

- 主题级样式使用 CSS Modules，变量封闭在主题根节点。
- 复杂状态与布局连续性使用 `motion/react`；环境氛围优先 CSS；数据图形优先 SVG。
- 指针视差通过 CSS 自定义属性传递，避免每帧触发 React state。
- 所有可交互装饰使用真实 `button`、可读名称和键盘路径。
- 弹层必须可退出，计时与持续动画必须可暂停。
- 桌面、平板、手机分别设计，不把桌面画布等比缩小。
- 尊重 `prefers-reduced-motion`，并确保信息不依赖运动出现。
- 概念页可以更大胆；进入正式产品前，需要重新通过信息密度、性能、无障碍和“第十天测试”。

## 9. 最终评审清单

### 概念

- [ ] 能否用一个动词概括主题，而不是只用一个形容词？
- [ ] 任务、进度、错误和完成是否都遵循同一隐喻？
- [ ] 学科表达是否真实，不会误导专业用户？

### 视觉

- [ ] 一级焦点是否唯一？
- [ ] 是否只拉高一到两个大胆旋钮？
- [ ] 正文区域是否保持安静和足够对比？

### 交互与动效

- [ ] 每个动效是否承担定向、因果、连续或奖励职责？
- [ ] 操作是否形成入口、反馈、结果、下一步闭环？
- [ ] 退出是否比进入快？持续运动是否可停？

### 长期使用

- [ ] 三秒内能否找到当前最重要的动作？
- [ ] 第十天后，动态元素仍然提供信息吗？
- [ ] 手机与减少动效模式下，故事和操作仍然完整吗？

真正可复用的不是某个渐变、光晕或弹簧参数，而是这条链路：**用一个准确的认知隐喻重写信息结构，再用克制而有因果的动效让它变得可感知。**
