# Ascend 学习驾驶舱重构实施计划

## 阶段 1：数据与设计基础

1. 追加任务调度迁移和 repo 测试。
2. 扩展任务 Server Action，覆盖排期、优先级、时长、备注与跨日移动。
3. 扩展考试里程碑科目关联与目标分数。
4. 建立 Summit Atelier 令牌、全局壳层、导航分组、页面标题和 View Transition 基础。
5. 形成 `feat: 建立学习驾驶舱基础` 恢复提交。

## 阶段 2：首页、今日与日历

1. 首页增加今日时间线、容量、考试风险与近期轨迹。
2. 今日任务计划器增加调度字段、排序层级和执行状态。
3. 日历增加任务事件、考试里程碑、未排任务抽屉、拖动排期与缩放时长。
4. 增加日历与任务联动测试和 Playwright 核心路径。
5. 形成 `feat: 重构每日计划与日历调度` 恢复提交。

## 阶段 3：知识、复习与错题

1. 科目总览升级为风险和投入视图。
2. 知识工作台统一树、画布、详情和上下文动作。
3. 知识点增加“加入今日训练”。
4. 复习队列升级进度、考试语境、结果反馈和离线同步状态。
5. 错题本增加状态筛选、原因与知识上下文。
6. 形成 `feat: 重构知识与主动回忆闭环` 恢复提交。

## 阶段 4：考试与分析

1. 考试里程碑进入模考与学习分析上下文。
2. 模考趋势升级为时间序列、能力分解和建议训练动作。
3. 分析弱点精确链接知识点并支持生成训练任务。
4. 形成 `feat: 打通考试诊断与训练反馈` 恢复提交。

## 阶段 5：资料与辅助页面

1. 资料库升级目录、内容、检查器和批量操作布局。
2. 设置升级分类导航与内容工作区。
3. 登录、引导、空状态、错误页、管理页统一品牌语言。
4. 形成 `feat: 完成全站视觉系统` 恢复提交。

## 阶段 6：验证与发布

1. 执行单元测试、Lint、构建、迁移校验、备份校验。
2. 在隔离数据实例验证桌面、平板、手机和核心写路径。
3. 检查减弱动效、键盘焦点、横向溢出、触控尺寸和动画性能。
4. 生成交付报告和页面截图。
5. 推送 `agent/visual-rebuild-v1` 并保留稳定基线标签。
