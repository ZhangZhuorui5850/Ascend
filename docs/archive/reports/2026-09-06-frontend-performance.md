# 前端性能与交互修复验收

日期：2026-09-05 至 2026-09-06。范围：全局导航、搜索、记录面板、资料库预览及共享无障碍样式。变更位于 `codex/frontend-performance-interactions`，未发布。

## 性能结果

同一台机器、Next.js 生产构建、隔离测试账号，刷新页面后等待资源加载稳定；统计 Resource Timing 中 `_next/static/*.js` 的 `decodedBodySize`，包含页面自动预加载，未打开搜索或文件预览。单位为字节，属于解压后脚本加载量，并非压缩网络流量、LCP 或操作延迟。

| 页面 | 修改前 | 修改后 | 减少 |
| --- | ---: | ---: | ---: |
| 今天 | 1,439,521 | 784,572 | 45.5% |
| 资料库 | 1,439,521 | 839,803 | 41.7% |

[测量数据](../../screenshots/frontend-performance-2026-09-06/metrics.json)。后续仅补充 `.srOnly` CSS，未改变 JavaScript 行为。

原导航强制预加载全部可见入口，导致首页和资料库停留后下载相同的大量跨页脚本。现在仅在鼠标悬停、键盘聚焦、触摸入口时预加载对应目的地。全局搜索首次打开才加载，之后保留挂载以维持退出动画和查询状态。资料库提取轻量文件类型判断，预览窗口和 Markdown 渲染分别按需加载。首次打开这些功能仍需请求其代码；未靠隐藏功能或减少业务数据实现优化。

## 交互修复与证据

- 搜索键盘滚动：修改前选中末项时列表底部 625.99px，结果底部 950.30px，scrollTop 为 0；修改后 scrollTop 为 324.5px，结果底部 625.80px，已进入可见区。[桌面截图](../../screenshots/frontend-performance-2026-09-06/after-keyboard.png)。
- 输入法：派发 `isComposing=true` 的 Enter 后，搜索窗口继续打开；不会执行候选结果。全局快捷键同样避开输入法组合事件与已被消费的事件。
- 拖放：修改前向资料库投放测试文件会唤起记录窗口，[错误表现](../../screenshots/frontend-performance-2026-09-06/before-drop.png)。修改后局部上传区先消费事件，测试 TXT 和 Markdown 均成功进入资料库，没有额外打开记录；拖动提示也让局部上传区优先。
- 文件预览：TXT、Markdown 均可正常打开。预览改用 Base UI Dialog，焦点先到关闭按钮，Tab 留在窗口内，Escape 后恢复到原来的预览按钮。
- 请求取消：在隔离页面中临时模拟未完成的文本下载，关闭预览后观察到 AbortSignal 被取消；随后刷新页面清除测试插桩。不同文件使用独立文本预览状态，避免复用旧内容或错误。
- 无障碍文本：搜索与日历使用的全局 `srOnly` 样式缺失。补齐共享样式，保留读屏语义并移出可见布局。

## 验证

- 全量 Vitest：135 个文件、762 项测试通过；最终相关模块复跑：6 个文件、26 项通过。
- TypeScript、ESLint、生产构建通过。
- CSS 架构、动效审计通过。
- 隔离 `ci:e2e` responsive 套件通过：9 个路由 × 6 种视口，以及导航定位、主题切换、PWA、standalone 安全区和全局记录快捷键。
- 另在 390 × 844 下验证搜索首次打开与末项键盘滚动，无横向溢出。[最终手机截图](../../screenshots/frontend-performance-2026-09-06/mobile-search.png)。
- 最后新增共享隐藏样式后重建，并对搜索计算样式和手机截图做定向复验。

浏览器测试只使用专用临时数据库和测试文件；不涉及真实用户数据、GitHub 推送或生产部署。本次未做线上 Core Web Vitals 长期采样、真实手机或大型历史资料库压力测试，因此不将脚本减少比例表述为全站提速比例。
