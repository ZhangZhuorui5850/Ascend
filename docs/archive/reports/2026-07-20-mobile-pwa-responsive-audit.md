# 移动端、PWA 与跨页定位深度审计

日期：2026-07-20

## 结论

- [COMPUTED] iPhone 添加到主屏幕后底部导航异常偏高，根因是安全区被计算两次：基础样式把 `safe-area-inset-bottom` 加进导航高度与内边距，主题样式又把整条导航向上移动同样的距离。
- [COMPUTED] 从首页跳到 `/day/<date>#day-tasks` 时，目标顶部曾落在 `-7.7px`，而粘性顶栏底部为 `64px`，目标被完整遮挡。
- [COMPUTED] 学习分析页的弱点链接传入知识点 ID，但科目页原先只按章节 ID 解析 `focus`，会错误显示“聚焦的章节不存在”。
- [COMPUTED] 1440px 桌面设置页曾有 31px 横向溢出，来源是关闭状态的固定收纳抽屉仍被计入文档滚动宽度。
- [COMPUTED] 移动端固定备案号会压在正文和底部导航之间，320px 短屏尤其明显。

## 修复

1. 统一安全区变量，普通浏览器保留悬浮底栏；standalone 模式改为 68px 内容栏加独立安全区填充，不再把安全区算进导航内容高度。
2. 顶栏在移动端按 `58px + 顶部安全区` 计算，主内容按底栏实际几何预留空间；键盘打开时继续隐藏底栏。
3. 为今日工作台与设置锚点增加粘性顶栏偏移，跨页导航恢复到页面顶部。
4. `focus` 同时支持章节和知识点；知识点深链会收敛到所属章节、渲染面包屑、突出目标，并在 View Transition 完成后再滚动与聚焦，避免过渡截图错位。
5. 移动端备案号回归文档流；关闭的收纳抽屉由页面横向裁剪边界隔离。
6. 移动底栏主链接点击后同步关闭“更多”菜单。
