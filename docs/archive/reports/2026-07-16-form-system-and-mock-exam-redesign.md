# 模考与表单系统重构报告

日期：2026-07-16

## 设计结论

- [KNOWN] 模考记录采用“考试结果—能力诊断—复盘决策”三段结构，保存后进入成绩趋势、薄弱维度和历史档案。
- [KNOWN] 高频离散输入使用预设按钮与选择卡；精确数值保留直接输入能力。
- [KNOWN] 长文本区域只承载复盘证据、检索备注和学习目标，所有编辑器提供明确任务提示。
- [KNOWN] 主操作统一放在流程末端，并通过完整度、修改状态和保存反馈表达当前状态。

## 全局审计与处置

| 场景 | 审计结论 | 处置 |
| --- | --- | --- |
| 模考记录与历史 | 六个等权输入缺少任务层级，复盘与成绩关系较弱 | 重构为三段式诊断流程，加入实时得分率、时长预设、能力滑杆、失分标签、下一轮重点和历史能力条 |
| 知识点详情 | 需要稳定的结构定位与学习加工关系 | 延续图谱/目录 + 右侧学习工作台设计，主动回忆、资料、错题、复习轨迹独立分区 |
| 资料元数据 | 字段连续堆叠，关联层级和保存状态较弱 | 重构为基本信息、三级学习位置、检索备注；加入修改检测、保存反馈与同步基线 |
| 学习设置 | 目标、时长、倒计时和复习容量权重接近 | 建立目标编辑器、节奏预设、结构化里程碑行、容量选择卡和集中保存区 |
| 初始引导 | 精确数值输入承担主要选择任务 | 每周投入和每日复习改为预设卡，考试里程碑独立成组，精确设置收纳为高级区 |
| 新建科目 | 编号、名称、类型和提交操作缺少视觉分组 | 建立主线说明、字段卡、方向选择卡和明确主按钮；桌面使用 12 列网格，手机使用单列布局 |
| 快速记录、日记、任务 | 输入与单个即时动作直接对应 | 维持任务型内联结构和快捷操作，保持录入速度 |
| 登录、密码、邀请、管理操作 | 安全流程依赖成熟表单习惯 | 维持标准字段顺序、显式标签、错误提示和确认操作 |

## 模考信息架构

1. 考试结果：名称、日期、范围、得分、满分、计时用时。
2. 能力诊断：概念掌握、计算准确、时间控制，统一使用 0–100 训练维度。
3. 复盘决策：失分类型、关键证据、下一轮动作和验证标准。
4. 结果反馈：平均值、最佳值、最近变化、首要短板和历史表现档案。
