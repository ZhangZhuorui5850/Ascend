## 尚未取得的外部证据

### 独立 Judge

当前 Codex 沙箱不能访问 Docker daemon，且不允许创建回环监听端口；因此不能在本机
伪造“完整 Judge 已验收”。独立主机准备好后必须完成：

1. 固定镜像 digest、生成 SBOM、扫描漏洞；
2. 启动独立 Gateway / Judge0 / Worker；
3. 运行 `npm run audit:judge-isolation`；
4. 运行 `npm run audit:judge-chain`；
5. 验证无网络、无主应用数据卷、单进程和配额终止；
6. 设置 `ASCEND_JUDGE_PILOT_REQUIRED=true` 后，只批准内部阶段 0 账号。

### 真实终端

监听端口限制也阻止了 Playwright 驱动本轮产物。脚本已覆盖 390×844、768×1024、
1440×900 的托管编辑器和 30 题目录，但仍需在可监听环境执行
`npm run responsive:audit`，并补真实 iPhone Safari/PWA 冒烟。

### Git 收口

尝试创建 `codex/algorithm-plugin-pilot` 分支时，环境不允许写 `.git` 元数据；
审批通道也未能正常处理请求。因此本轮没有创建分支、暂存、提交或推送。工作区原本就
包含大量同一升级批次的未提交改动，交接时应先按报告和功能边界拆分审阅，不应把它们
误当作一份全新的干净 diff。

## 发布结论

应用代码、题库、试点治理和本地可执行验证已达到“等待隔离环境验收”的状态；
尚未达到“在线 Judge 已生产上线”的状态。发布顺序必须是：独立基础设施安全验收 →
内部账号阶段 0 → 5–8 人可用性试点 → 10–20 人学习流程试点，而不是直接全量开放。
