# Ascend Practice 题目管理导航设计

日期：2026-08-26

## 目标

侧栏围绕三个稳定问题组织：现在学什么、怎样找到题目、怎样保存个人整理。课程、来源、知识点、难度和状态各自保持单一职责，同一道题通过虚拟视图从多个维度访问。

## 模式导航

```text
学习模式
├── 当前课程
├── 今日任务
├── 到期复习
└── 继续上次

题库模式
├── 全部题目
├── 课程与题单
├── 知识点
├── 来源
├── 难度
└── 学习状态

目录模式
├── 用户文件夹...
└── 未整理
```

侧栏一次显示一个模式，视图标题按钮和固定模式根节点菜单负责切换，选择保存在工作区状态中。“当前课程”由用户从已有课程与题单中选择，课程内部按阶段组织题目。题库模式全部由题目元数据计算。目录模式沿用服务器个人文件夹和稳定排序，根层题目集中显示在“未整理”。

## 文件夹操作

- 目录模式的工具栏“新建文件夹”在根层创建；文件夹菜单在当前文件夹内创建子文件夹。
- 文件夹支持重命名、置顶、上下移动、拖入父文件夹、移回根层、生成本地多根工作区。
- 删除提供“内容提升到上一级”和“删除空文件夹”两条明确路径。
- 学习模式、题库模式和搜索结果中的题目通过“移动到文件夹”选择器归档。
- 目录模式支持拖拽整理；拖到模式根节点或“未整理”会移动到个人目录根层，拖到题目会放在该题之后。
- 多选拖动会去重，并跳过已随父文件夹一起移动的后代项目。
- 每次移动保存原位置并提供一次撤销；服务端继续保护文件夹循环、同级重名和工作区隔离。
- 虚拟分类保持只读结构，拖动其中的题目只更新个人目录位置。

## 状态保持

- 固定模式节点使用稳定 ID，由 VS Code 保存折叠状态。
- 当前模式、个人文件夹展开状态、当前选择、排序方式和当前课程保存在 workspaceState。
- 虚拟目录调整只更新服务端组织关系，本地 `main.cpp` 路径保持稳定。
