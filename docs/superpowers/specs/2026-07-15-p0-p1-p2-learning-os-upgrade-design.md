# Ascend P0–P2 学习操作系统升级设计

日期：2026-07-15

## 目标

把现有的知识管理与日工作台升级为完整学习闭环：完成初始化后，学习行为自动进入复习管线；复习、错题、模拟考试和考试日期共同驱动每日优先级；资料与学习记录可以批量整理、重新关联并在移动端高效使用；当日复习在短时断网下可继续完成并在联网后安全提交。

## P0：学习正确性与发布门禁

### 学习状态机

- `knowledge_points` 新增 `prompt`、`answer`、`interval_step`、`lapse_count`、`last_score`。
- 首次学习某知识点时，将状态设为“学习中”，`interval_step=0`，`next_review=D+1`。
- 评分 0/1：`interval_step=0`、`lapse_count+1`、`next_review=D+1`。
- 评分 2：`interval_step+1`，按 1/3/7/16/30 天阶梯排期。
- 评分 3：首次成功仍从 3 天开始，后续可前进两级；最长 30 天。
- `reviews` 保留为累计统计，不再参与间隔阶梯计算。
- 到期队列按 `精通 → 掌握 → 了解`、逾期日期、低掌握度排序。

### 错题回炉

- `mistakes` 新增 `pass_count` 与 `cause_category`。
- 第一次“已会”排 D+4，第二次跨日“已会”毕业。
- “仍错”重置 `pass_count` 并排 D+1。
- 关联知识点的错题继续回写复习事件与掌握度。

### 关联入口

- 快速学习和错题记录支持科目、章节、知识点级联选择。
- 关联知识点的学习记录自动触发首次排期。
- 知识点提供“今天学了”操作，可独立触发首次排期。

### 工程门禁

- 固定 Node 22，并在本地安装提示、Docker 与 CI 中一致执行。
- GitHub Actions 执行 `npm ci`、测试、Lint、构建和迁移验证。
- 上传的数据库写入使用事务；文件写入失败或事务失败都有补偿清理路径。
- 全站增加 CSP、防嵌入及基础安全响应头。
- 备份脚本输出机器可读状态，提供异地同步脚本入口和成功标记。

## P1：学习效果与首次体验

### 初始化向导

- 新用户首次进入学习区时完成四步：考试目标、考试日期、启用科目、每周可投入时间。
- 设置存储于 `app_settings`；完成标记为 `onboarding_completed`。
- 初始化后首页生成首个可执行动作，并引导选择一个知识点开始学习。

### 主动回忆

- 复习卡先展示 `prompt`，用户点击“显示答案”后展示 `answer` 和评分。
- prompt 为空时使用知识点标题；answer 为空时展示关联错题与资料提示。
- 离线队列保存复习项目的最小快照，提交使用客户端操作 ID 保证幂等。

### 积压恢复

- 积压达到阈值时显示恢复面板。
- 用户可选择 3/7 天清理窗口；系统按重要性和考试临近度生成每日额度。
- 允许将低重要性、高掌握度项目顺延，所有顺延写入审计事件。

### 考试冲刺与模拟考试

- 最近考试日期进入弱点优先级，临近考试逐步提高真题、错题、低掌握度权重。
- 新增模拟考试记录：名称、日期、得分、满分、耗时、科目、复盘和能力拆分。
- 分析页展示成绩趋势、能力薄弱项、复习留存与计划完成情况。

## P2：移动端与资料生产力

### 移动信息架构

- 手机日历默认日程列表；桌面保留 FullCalendar 月视图。
- 今日页使用可折叠分区，并提供手机模块导航。
- 主要动作保持 44px 触控区域并适配安全区。

### 资料库

- 列表/网格视图切换，图片通过鉴权附件端点展示预览。
- 支持多选、全选当前页、批量移动和批量删除。
- 主文件区接受操作系统拖入上传。
- 上传使用三并发队列，显示逐文件状态与总进度。
- 详情面板可修改日期、科目、章节、知识点、分类和备注。
- 搜索覆盖文件名、备注、科目、章节和知识点标题。

### 离线复习

- Service Worker 只缓存公共离线页和图标；登录态复习快照存入按工作区隔离的 IndexedDB。
- 离线评分写入 IndexedDB outbox，包含 `operationId`、日期、知识点和评分。
- 联网后按 operationId 幂等提交；冲突以服务端已接受事件为准并刷新队列。
- 退出账号时清除该设备的私有复习快照与 outbox。

## 验收

- 全量测试、Lint、构建、迁移验证通过。
- 新用户从初始化到首次学习、D+1 复习排期全链路通过。
- 遗忘重建、错题两次通过、积压恢复和冲刺优先级都有 repo 测试。
- 390px 触屏完成任务、复习、手机日历、资料批量移动与重新关联。
- 离线完成评分、恢复网络、幂等同步和退出清理通过端到端验证。
- 备份产物包含成功标记，恢复演练能还原数据库与上传文件。
