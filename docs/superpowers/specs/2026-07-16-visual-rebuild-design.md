# Ascend 学习驾驶舱视觉与交互重构设计

## 目标

Ascend 升级为“考试驱动的每日学习驾驶舱”。界面围绕一个连续闭环组织：目标与考试定义方向，任务与日历分配时间，知识点与资料提供上下文，复习与错题巩固记忆，模考与分析生成下一轮训练动作。

## 设计原则

1. **行动优先**：每个核心页面都有一个清晰的下一步动作，首页回答“现在做什么”，今日页回答“怎样完成”，分析页回答“接下来练什么”。
2. **时间可见**：任务同时拥有日期、优先级、预计时长和可选开始时间，日历成为学习容量的真实投影。
3. **上下文连续**：科目、知识点、错题、复习、资料、模考和训练任务之间通过显式链接保持上下文。
4. **层级克制**：应用外壳保持安静，主要工作区获得最高对比度，辅助数据使用渐进披露。
5. **动效表达含义**：共享元素表示深入同一对象，纵向揭示表示数据到达，横向位移表示前进与返回，交叉淡化表示同位置内容切换。
6. **恢复可靠**：数据层迁移只追加，功能按阶段提交，重构分支与稳定标签共同提供恢复路径。

## 视觉方向：Summit Atelier

- **气质**：现代学习工作室、精密仪表、温暖纸张与克制数字界面。
- **主色**：墨黑承担应用外壳，暖白承担工作区，朱砂承担关键动作，鼠尾草绿承担完成与掌握。
- **层级**：页面背景、工作表面、浮层、聚焦表面四级；边框从描边升级为柔和内阴影与局部高光。
- **排版**：标题使用具有人文感的 serif/display 栈，正文与控件使用高可读 sans，数字使用 tabular numerals。
- **空间**：桌面内容上限 1440px，核心页允许宽工作台；移动端使用 16px 页面边距和 72px 底部导航安全区。
- **形状**：容器圆角 16–24px，控件圆角 10–14px，状态胶囊使用完整圆角。

## 信息架构

### 全局导航

- 今日：主页、今日工作台、日历
- 学习：科目、错题本、模考
- 资源：资料库、学习分析
- 系统：设置、账户、命令面板、快速收纳

桌面侧栏显示分组和当前页面状态；折叠态保留图标、提示和活动指示。移动端固定“主页、今日、日历、复习、更多”，收纳作为居中的主动作。

### 首页

- “现在”主卡：根据到期复习、高优任务和考试临近程度选择主动作。
- 今日时间线：展示已排时任务、自由任务、复习容量和考试节点。
- 学习健康度：周目标进度、连续天数、复习负债、任务完成率。
- 科目风险：结合到期复习、未毕业错题、掌握度和考试日期排序。
- 最近轨迹：学习、复习、错题、资料和模考形成统一活动流。

### 今日工作台

- 左侧为任务计划器，支持优先级、时长、时间、科目、完成、顺延和快速编辑。
- 主区域为执行流，按时间排序已排任务，复习队列作为学习块参与容量计算。
- 右侧为快速记录、今日资料和学习轨迹。
- 移动端使用模块切换与底部抽屉保持单任务聚焦。

### 日历

- 桌面默认周视图，月视图用于节奏回顾，列表视图用于移动端。
- 任务以时间块出现，拖动修改日期与开始时间，缩放修改预计时长。
- 未排时任务显示在计划抽屉中，可拖入日历。
- 考试里程碑、复习负债、学习记录和错题使用不同语义层级。
- 日期点击进入对应工作台，事件点击保留来源上下文。

### 科目与知识工作台

- 科目列表显示掌握度、复习负债、错题、资料和近期投入。
- 科目详情继续提供大纲与思维导图双视图，详情面板集中展示回忆卡、掌握度、关联资料、错题与复习历史。
- 知识点可以直接生成今日训练任务，分析页的弱点链接精确聚焦知识点。
- 桌面使用“导航树 / 知识画布 / 详情面板”，移动端使用层级列表与详情全屏层。

### 复习与错题

- 今日复习使用沉浸式队列，显示进度、来源科目、考试关联和评分后的下一次日期。
- 错题本按“到期、回炉中、已毕业”形成状态管道，并提供原因、知识点和科目筛选。
- 完成反馈展示掌握度变化和队列剩余量。

### 考试与模考

- 考试里程碑关联可选科目和目标分数，进入首页、日历、复习冲刺判断和分析页。
- 模考记录展示成绩趋势、能力分解、薄弱领域和建议动作。
- 薄弱领域可以直接生成带科目、优先级和时长的训练任务。
- 考试页展示剩余容量、建议周投入和近期复习负债。

### 资料库与设置

- 资料库采用成熟的文件管理布局：目录树、内容区、详情检查器、批量操作和搜索。
- 设置采用左侧分类导航与右侧内容区，学习目标、考试里程碑、外观、显示、设备和安装保持独立分组。
- 登录与引导采用品牌化全屏画面，并用分步进度表达首次设置过程。

## 数据关系

```text
考试里程碑 ── subject_code ──> 科目
      │                           │
      ├─ 日期进入日历             ├─ 章节 ─> 知识点
      ├─ 驱动冲刺复习             │             ├─ 复习事件
      └─ 影响首页风险排序          │             ├─ 错题
                                  │             └─ 资料链接
任务 ── day/start/duration ──> 日历/今日
  └─ subject_code ──────────> 科目
模考 ── subject_code ───────> 科目
  └─ 薄弱领域 ──────────────> 训练任务
分析弱点 ── point_id ───────> 知识点详情/训练任务
```

### 任务模型扩展

- `priority`: 1 高、2 中、3 低。
- `estimated_minutes`: 5–480 分钟。
- `scheduled_start`: 可选 `HH:MM`，为空表示当天待安排。
- `notes`: 简短执行上下文。

任务跨日移动在事务中更新日期和排序；日历拖动同时更新日期与开始时间；缩放更新时间预算。所有写入继续经过 Server Action、workspace 鉴权、repo 和 `revalidatePath`。

### 考试里程碑扩展

设置 JSON 中增加可选 `subjectCode` 与 `targetScore`。旧数据读取时获得空关联，保存时校验科目属于当前 workspace。

## 动效系统

- 即时反馈：120–160ms，按钮、悬停、复选和选中状态。
- 组件变化：180–240ms，卡片展开、抽屉、筛选和列表重排。
- 页面导航：280–420ms，共享元素、内容方向和加载揭示。
- 成就反馈：420–650ms，任务完成、复习清空和掌握度升级。
- 通用属性采用 `transform` 与 `opacity`；布局动画使用 View Transition 快照。
- `prefers-reduced-motion` 与应用内减弱动效设置将位移动画降级为短淡化。

## 响应式策略

- `>= 1280px`：三栏工作台和宽周历。
- `901–1279px`：折叠侧栏、双栏内容、详情抽屉。
- `<= 900px`：底部导航、单栏内容、底部抽屉。
- `<= 480px`：紧凑指标、44px 触控目标、16px 表单字号、模块级渐进披露。

## 验收标准

1. 全部用户页面使用统一应用壳层、标题体系、表面层级和响应式规则。
2. 任务支持优先级、时长、时间与科目，并在今日页和日历双向同步。
3. 考试里程碑可关联科目，并同时出现在首页、日历和考试上下文。
4. 分析弱点与模考建议可以生成训练任务。
5. 知识点、错题、复习、资料和训练动作保留可追踪关联。
6. 页面导航、抽屉、任务完成、复习评分和拖拽拥有语义动效。
7. 桌面、平板、手机、键盘、减弱动效和高对比模式通过验证。
8. `npm test`、`npm run lint`、`npm run build` 与隔离端到端验证全部通过。
